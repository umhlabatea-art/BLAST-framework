# SaaS Customer Success Kit — Prompt Pack (Core)

> **Every output is a draft.** Match your product's real capabilities and brand
> voice, and never promise an SLA, roadmap item, or feature that isn't real. Keep
> customer data out of public AI tools. See `DISCLAIMER.md`. Replace every
> `[BRACKET]`.

---

## Shared inputs

```
Product: [WHAT IT DOES]
Customer segment: [SMB / MID-MARKET / ENTERPRISE]
Their goal / desired outcome: [WHY THEY BOUGHT]
Key activation event(s): [THE "AHA" ACTIONS]
Brand voice: [e.g. helpful, concise, human]
```

---

## 1. Onboarding email sequences

### 1.1 — Onboarding sequence

```
Write a [NUMBER]-email onboarding sequence that gets a new customer to their
first value milestone.

Milestone / activation event: [EVENT]
Cadence: [DAYS]
[PASTE SHARED INPUTS]

Each email: subject (+alt), under 130 words, one clear next step toward the
milestone, and a link placeholder to the relevant help doc. Progress logically;
don't dump every feature. Return as a table.
```

---

## 2. In-app / lifecycle messaging

### 2.1 — In-app nudge set

```
Write a set of [NUMBER] in-app messages (tooltip/banner/modal) that nudge users
toward [BEHAVIOR].

Trigger for each: [e.g. "hasn't invited a teammate after 3 logins"]
[PASTE SHARED INPUTS]

Keep each under 2 short sentences, action-oriented, with a single CTA label. Note
the ideal trigger and placement for each. No dark patterns.
```

---

## 3. QBR / business-review narratives

### 3.1 — QBR narrative

```
Draft the narrative for a Quarterly Business Review with [CUSTOMER].

Their goals this period: [GOALS]
Usage & outcome data I'm providing (use only these): [METRICS]
Wins to highlight: [WINS]  ·  Risks/opportunities: [ITEMS]
Ask / next steps: [e.g. expansion, renewal, exec sponsor]

Structure: Goals → What we achieved (tie to their goals) → Value delivered →
What's next → Recommendation. Executive tone. Do not invent metrics; use only
what I provided. Flag any number I should double-check.
```

---

## 4. Churn-save & win-back scripts

### 4.1 — Churn-save script

```
Write a churn-save outreach (email + talk-track bullets) for an at-risk account.

Risk signals: [e.g. usage drop, support escalations, champion left]
What we can genuinely offer: [REAL OPTIONS — training, re-onboarding, roadmap
item that actually exists]
[PASTE SHARED INPUTS]

Empathetic, diagnostic (understand why before pitching), and honest about what we
can do. No desperate discounting language and no promises we can't keep. Provide
3 discovery questions to ask first.
```

### 4.2 — Win-back email

```
Write a win-back email to a churned customer [TIMEFRAME] after they left. Lead
with what's genuinely changed/improved (only real items: [CHANGES]), acknowledge
their reason for leaving if known ([REASON]), low-pressure CTA to reconnect.
Under 120 words.
```

---

## 5. Help-doc / knowledge-base drafts

### 5.1 — Help-doc article

```
Write a knowledge-base article explaining how to [TASK] in [PRODUCT].

Audience skill level: [BEGINNER/ADVANCED]
Steps (from my notes): [STEPS]
Common pitfalls: [PITFALLS]

Structure: what this lets you do, prerequisites, numbered steps, screenshots
placeholders, troubleshooting, related articles. Clear and scannable. Do not
invent UI that doesn't exist — use only the steps I gave.
```

---

## 6. Expansion / upsell outreach

### 6.1 — Expansion outreach

```
Write expansion outreach to a healthy account that's a fit for [UPSELL/CROSS-SELL].

Why they're a fit (usage signals): [SIGNALS]
The value of the expansion for them: [OUTCOME]
[PASTE SHARED INPUTS]

Lead with their outcome, not our revenue. Tie the recommendation to their usage.
Soft CTA to explore. No pressure. Under 140 words.
```
