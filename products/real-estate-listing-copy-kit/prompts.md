# Real Estate Listing & Client Copy Kit — Prompt Pack (Core)

> **Fair-housing rule, applied to every prompt: describe the _property_, never
> the _people_ who might live there.** No language that indicates a preference,
> limitation, or steering based on race, color, religion, sex, disability,
> familial status, or national origin — or any proxy for them (e.g. "perfect for
> a young family", "great for empty nesters", "safe neighborhood", "walking
> distance to churches"). Review every output before publishing. See
> `DISCLAIMER.md`. Replace every `[BRACKET]`.

---

## 1. MLS listing descriptions

### 1.1 — Listing description

```
Write an MLS listing description for this property. Describe the home and its
features only — never the ideal buyer, family type, or neighborhood
demographics.

Property type: [TYPE]  ·  Beds/baths: [#/#]  ·  Sq ft: [#]  ·  Lot: [SIZE]
Standout features: [FEATURES]
Recent updates: [UPDATES]
Location features (factual amenities, not demographics): [e.g. "0.3 mi to X park",
transit, schools BY NAME if factual]
Tone: [e.g. warm, upscale, straightforward]
Length: [WORD COUNT]

Do NOT use protected-class or steering language. At the end, list any phrase you
think I should double-check for fair-housing compliance.
```

### 1.2 — Fair-housing review of existing copy

```
Review this listing description for fair-housing compliance. Flag any language
that could indicate a preference, limitation, or steering based on a protected
class (or a proxy), explain why, and suggest a property-focused replacement.

Listing:

[PASTE LISTING]
"""
```

## 2. Buyer emails

### 2.1 — New-listings email to a buyer

```
Write a short email to a buyer client sharing [NUMBER] new listings that match
their criteria.

Their stated criteria (features only): [BEDS, BUDGET, AREA, MUST-HAVES]
Listings to include: [ADDRESSES OR MLS #s + one highlight each]

Warm, helpful, clear CTA to book showings. Reference the homes' features, not
assumptions about the client. Under 150 words.
```

---

## 3. Seller emails / listing presentations

### 3.1 — Listing-presentation talking points

```
Create talking points for a listing presentation to a prospective seller.

Property: [ADDRESS/TYPE]  ·  My comparative advantage: [YOUR VALUE]
Recent comparable sales: [COMPS IF KNOWN]
Marketing plan highlights: [CHANNELS]

Produce: opening, pricing-strategy framing (note final price is the seller's
decision and depends on a CMA), marketing plan, and a close. Confident, honest,
no guaranteed-sale promises.
```

## 4. Social captions

### 4.1 — Listing social captions

```
Write 3 social captions (Instagram, Facebook, one short-form video hook) for this
listing. Feature-focused, fair-housing-safe, with a CTA and placeholder for the
link. Vary length. Suggest 5 relevant, non-demographic hashtags.

Property highlights: [FEATURES]  ·  Price: [PRICE OR "contact for pricing"]
```

---

## 5. Market-update content

### 5.1 — Neighborhood market update

```
Write a monthly market-update email for [AREA] using the data I provide. Do not
invent statistics.

Data (only what I give you): [MEDIAN PRICE, DOM, INVENTORY, MoM/YoY]
Audience: [BUYERS/SELLERS/BOTH]

Explain what the numbers mean for the reader in plain English, balanced (not
hype), with a soft CTA to reach out. Keep any forward-looking statement clearly
hedged.
```

---

## 6. Negotiation & offer scripts

### 6.1 — Offer / counter script

```
Draft a professional message to the other agent conveying my client's
[OFFER/COUNTER] on [ADDRESS].

Key terms: [PRICE, CONTINGENCIES, TIMELINE, INCLUSIONS]
Tone: firm but collaborative.

Keep it factual and terms-focused. Do not disclose my client's motivations or
anything confidential. Remind me (in a note) of anything I should confirm with my
client before sending.
```
