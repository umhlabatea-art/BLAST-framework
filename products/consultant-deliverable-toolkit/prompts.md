# Consultant Deliverable Toolkit — Prompt Pack (Core)

> **Every output is a draft. Your expertise and judgment are the actual
> deliverable — review and edit before anything reaches a client.** Read
> `DISCLAIMER.md`, especially on client confidentiality: never paste a client's
> non-public information into a public AI tool. Replace every `[BRACKET]`;
> delete _italic_ guidance.

## 1. Proposals / SOWs

### 1.1 — Consulting proposal / SOW

```
You are an experienced management consultant drafting a proposal / statement of
work. Be specific and outcome-oriented; avoid filler.

Client & context: [CLIENT TYPE / INDUSTRY — no confidential specifics]
Problem to solve: [PROBLEM]
Desired outcome: [OUTCOME]
Scope of work: [WORKSTREAMS]
Out of scope: [EXCLUSIONS]
Timeline: [DURATION / MILESTONES]
Fee model: [FIXED / RETAINER / DAY RATE + AMOUNT]

Produce sections: Executive summary, Understanding of the problem, Approach &
methodology, Workstreams & deliverables, Timeline & milestones, Investment,
Assumptions & dependencies, About me/us, Next steps. Keep it confident and
concrete. Mark any number or claim I still need to verify with [VERIFY].
```

### 1.2 — Tighten a bloated proposal

```
Cut this proposal by ~30% without losing substance. Remove hedging and
buzzwords, sharpen the outcome language, and make the value obvious to a busy
executive. Return the tightened version plus a 3-bullet list of what you cut and
why.

Proposal:
"""
[PASTE — strip confidential client details first]
"""
```

## 2. Discovery-call frameworks

### 2.1 — Discovery-call question guide

```
Build a discovery-call framework for a prospective engagement about [PROBLEM
AREA].

Prospect role: [TITLE]  ·  Industry: [INDUSTRY]  ·  Call length: [MINUTES]

Produce: an opening (2 min), 4-6 themed question sets (current state, desired
state, obstacles, decision process, success metrics, budget/timeline), suggested
follow-up probes, and a close that proposes clear next steps. For each theme,
note what a strong answer tells me about fit.
```

## 3. Executive summaries

### 3.1 — Executive summary of findings

```
Write an executive summary for a [DELIVERABLE, e.g. diagnostic report] for a
senior/exec audience.

Situation: [1-2 SENTENCES]
Key findings (from my analysis): [BULLETS]
Recommendations: [BULLETS]
Expected impact: [QUANTIFIED IF POSSIBLE]

One page max. Lead with the "so what". Use the pyramid principle: answer first,
then support. Plain, decisive language — no hedging. Flag any claim needing a
data source with [SOURCE?].
```

## 4. Slide narratives

### 4.1 — Slide-by-slide storyline

```
Turn my findings into a slide storyline (I'll build the visuals). Use one clear
action-title sentence per slide (the takeaway, not the topic), then 2-4 supporting
bullets and a note on the ideal visual (chart type / framework / table).

Deck purpose: [DECISION IT DRIVES]
Audience: [WHO]
Findings & recommendations: [BULLETS]
Target length: [# SLIDES]

Structure as a logical argument that builds to the recommendation.
```

### 4.2 — Sharpen slide titles

```
Rewrite each of these slide titles as an action title — a full-sentence takeaway
a reader could grasp from the title alone. Keep them under 12 words.

Current titles:
"""
[PASTE TITLES]
"""
```

## 5. Client update emails

### 5.1 — Weekly engagement update

```
Write a concise weekly client update email.

Engagement: [NAME]  ·  Week of: [DATE]
Progress this week: [BULLETS]
Decisions needed from client: [BULLETS OR "none"]
Risks / blockers: [BULLETS OR "none"]
Next week: [BULLETS]

Professional, confident, skimmable. Put any client action items in a clearly
labeled section. Under [WORD COUNT] words.
```

## 6. Case-study write-ups

### 6.1 — Anonymized case study

```
Write a case study of a completed engagement for my marketing. Anonymize the
client unless I confirm written permission to name them.

Client descriptor (anonymized): [e.g. "a mid-market logistics firm"]
Challenge: [CHALLENGE]
What I did: [APPROACH]
Results (only metrics I can substantiate): [RESULTS]

Structure: Challenge → Approach → Results → (optional) client quote placeholder.
Compelling but truthful — do not invent or inflate any metric. Mark any figure I
must confirm before publishing with [VERIFY].
```
